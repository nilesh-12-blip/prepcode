## Features

- Multi-page premium UI with dark/light mode
- Topic navigation with visuals, syntax, tables, mistakes, and tricks
- Searchable question bank with show/hide solutions
- Bookmarking and progress tracking via `localStorage`
- Dedicated solution studio
- Quiz system with score history
- Smooth scrolling, animated reveals, responsive card layouts

## Run

1. Open the project in VS Code.
2. Use Live Server, or serve the folder with any static server.
3. Open `index.html`.

Example with Python:

```bash
python -m http.server 5500
```

Then visit `http://localhost:5500`.
